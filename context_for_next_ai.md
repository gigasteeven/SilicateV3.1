# Контекст проекта "Trakines" (Мод для Geometry Dash)

## Суть проекта
**Trakines** — это мод для Geometry Dash 2.2081, разрабатываемый на базе фреймворка **Geode SDK 5.7.1**.
Функционал — двойной рендеринг (dual-render pipeline):
1. **Игрок** видит геймплей в **Layout Mode** (синий фон, белые силуэты платформ, весь декор скрыт).
2. **OBS** через **Spout2** получает полный кадр со всеми декорациями и оригинальными цветами.
3. В меню, на паузе и в редакторе передается точная копия (1:1) экрана игры.

## Текущий статус (НА ЧЕМ МЫ ОСТАНОВИЛИСЬ)
1. **Весь исходный код уже написан.** Файлы лежат локально в репозитории и запушены на GitHub.
   - `src/main.cpp` — основные хуки (PlayLayer, CCDirector, LevelTools, CCKeyboardDispatcher).

   - `mod.json`, `.github/workflows/build.yml`.

## Что нужно сделать следующему ИИ:

Вам необходимо **получить логи ошибки сборки от пользователя** (чтобы он скопировал их из вкладки Actions на GitHub) и исправить код. 

Вот **наиболее вероятные причины ошибки сборки** в текущем коде (используется Clang + Geode 5.7.1):
1. Ошибки компилятора из-за **MSVC флагов** в `CMakeLists.txt`. Там есть блок `if(MSVC)` с флагом `/w`, но Geode Actions обычно собирает через `clang` (даже на Windows), возможно, cmake ругается на это.
2. Использование устаревшего `FetchContent_Populate(Spout2)` в `CMakeLists.txt` вместо `FetchContent_MakeAvailable(Spout2)`.
3. Ошибки в `main.cpp` при обращении к членам класса `GameObject`. Переменные типа `m_activeMainColorID`, `m_detailUsesHSV`, `m_hasNoGlow`, `m_isHide` могут иметь немного другие названия или геттеры/сеттеры в текущей версии биндингов Geode (5.7.1).
4. Ошибки в работе с `CCDirector::drawScene()` или `CCRenderTexture`. Возможно, `m_pRunningScene` требует другого аксессора.
5. Использование `Mod::get()->getSavedValue<bool>` вместо актуального API настроек (например, `Mod::get()->getSettingValue<bool>`).
