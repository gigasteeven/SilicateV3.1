# Контекст проекта "Trakines" (Мод для Geometry Dash)

## Суть проекта
**Trakines** — это мод для Geometry Dash 2.2081, разрабатываемый на базе фреймворка **Geode SDK 5.7.1**.
Функционал — двойной рендеринг (dual-render pipeline):
1. **Игрок** видит геймплей в **Layout Mode** (синий фон, белые силуэты платформ, весь декор скрыт).
2. **OBS** через **Spout2** получает полный кадр со всеми декорациями и оригинальными цветами.
3. В меню, на паузе и в редакторе передается точная копия (1:1) экрана игры.
